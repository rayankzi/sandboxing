# sandboxing

## Skills

- [`lecture-pdf-to-slides`](.claude/skills/lecture-pdf-to-slides/SKILL.md): turns annotated lecture-notes PDFs into a complete reveal.js + KaTeX HTML slide deck (every definition, theorem, example and instructor annotation carried over, with figures cropped from the PDF or drawn as SVG). It separates the instructor's ink from the print, keeps every handwritten mark in a toggleable ink layer, checks the rendered deck automatically (layout, math, text size, figures, ink layer, coverage of every inventory item and ink region), and ends with an independent review round.
